# 3. Топология компьютерных сетей

## Что такое сеть?

**Компьютерная сеть** — это система взаимосвязанных устройств, соединенных каналами связи для обмена информацией.

**Сетевой сегмент** - это часть сети, изолированная от других частей по физической или логической границе.

Основные компоненты сетей:
- Серверная инфраструктура
- Рабочие станции
- Сетевое оборудование
- Точка доступа

## Что такое топология?

**Топология сети** - совокупность соединений элементов сети друг с другом, которая определяет геометрическую структуру связей и логические правила взаимодействия сетевых узлов при передаче данных.

1. Физические связи между устройствами
2. Потоки трафика по сетям
3. Пути передачи данных
4. Методы адресации и маршрутизации

Ключевые критерии топологии:
1. Стоимость - бюджет на оборудование и инфраструктуру
2. Надёжность - возможность восстановления при отказе части системы
3. Масштабируемость - простота добавления новых узлов
4. Производительность - скорость передачи данных в сети
5. Безопасность - устойчивость к атакам через сегментацию и изоляцию

### Топология "Шина"

> Все устройства подключаются к единому коммуникационному кабелю (основной линии). Данные передаются на всех сегментах, но адресация направляет пакеты нужным узлам.

Характеристики:
1. недорого в реализации
2. простота в подключении
3. устарела из-за низкой безопасности и надежности
4. любая атака на шину влияет на всю сеть
5. широковещательные пакеты передаются всем устройствам, что упрощает перехват трафика
6. обрыв точки останавливает работу всей сети

### Топология "Кольцо"

> Устройства соединены в замкнутый круг, где каждый передает данные только соседу по кольцу.

Характеристики:
1. Передача данных по принципу "токена"
2. Если устройство выходит из строя, то сеть не работает
3. Применяется реже, сейчас заменено коммутаторами
4. трудно масштабировать без остановки сети

### Топология Mesh (Ячеистая)

> Каждое устройство подключается к нескольким другим, образуя многогранную структуру путей передачи данных. Позволяет альтернативные маршруты при отказе одного канала связи.

Характеристики:
1. максимальная надежность и отказоустойчивость
2. сложна в реализации и администрировании
3. требует больше оборудования (и кабелей)
4. высокая устойчивость к атакам на отдельные узлы
5. сложность контроля трафика по множеству путей
6. сложность обнаружения скрытых каналов передачи

### Топология "Звезда"

> Каждый узел подключается к центральному устройству (коммутатору или концентратору). Это стандартная топология для современных офисных сетей.

Характеристики:
1. Отказ одного устройства не влияет на работу остальных
2. простая в отладке и администрированию
3. высокая стоимость
4. изоляция портов, защита от широковещательных атак
5. центральный узел становится точкой отказа
6. возможности фильтрации (Access Control List) на уровне коммутатора

### Топология "Иерархическая звезда"

> Иерархическая структура, где узлы организованы по уровням и общаются только со своими непосредственными "начальниками" или "подчиненными".

Характеристики:
1. Масштабируемость
2. Управляемость
3. Надежность
4. Сложность проектирования и реализации
5. Центральный узел становится точкой отказа
6. Возможности фильтрации

### Гибридная топология

> Содержание разных типов топологий в одной сети, часто используется в крупных корпоративных структурах и кампусах

Характеристики:
1. Сегментация по функциям
2. Возможность использования разных протоколов на разных сегментах
3. Высокая сложность настройки и администрирования

## Концепция DMZ (Demilitarized Zone) - выделенная зона

+ **DMZ** - промежуточная зона между внутренней и внешней сетью, используемая для размещения публичных сервисов организации. Это архитектурный принцип защиты корпоративных систем от атак извне.

Назначение:
1. Размещение веб-, почтовых и других сервисов, доступных из интернета
2. Изоляция этих сервисов от внутренней сети с чувствительными данными
3. Снижение уязвимости при взломе внешних ресурсов

Варианты использования:
1. Место для внешних сервисов
2. Буферная зона

## Уязвимости при выборе неправильной топологии

- Логические угрозы
  - Отсутствие сегментации
  - Паралич сети при атаке на broadcast-трафик
  - ARP Spoofing (подмена MAC-адресов для перехвата трафика)
- Физические угрозы
  - Отсутствие изоляции портов в хабах
  - Прямая физическая связь между устройствами (отсутствие шифрования)
  - Открытые точки доступа без аутентификации
- Атаки типа MITM (man-in-the-middle):
  - атакующий внедряется в сеть (часто через слабый хаб или уязвимый роутер)
  - подменяет mac-адреса на уровне коммутатора
  - перехватывает данные, проходящие через его устройство

## Рекомендации по проектированию защищённых сетей

- Защита от атак типа MITM:
  1. Использование VLAN, ACL для изоляции сегментов
  2. Шифрование трафика (TLS/SSL)
  3. Мониторинг сетевого трафика на предмет аномалий
  4. Регулярное обновление оборудования

- Использование VLAN для сегментации:
  1. Логическое разделение сети на зоны по функциям
  2. Ограничение широковещательного трафика между сегментами
  3. Простота управления и администрирования

- Реализация принципа наименьших привилегий:
  1. Ограниченный доступ только к необходимым ресурсам
  2. Изоляция DMZ от внутренней сети
  3. Контролируемое движение трафика между сегментами

- Мониторинг сетевого трафика

## Хабы (Hubs)
- **Концентратор** — активное устройство первого уровня OSI, которое принимает данные на один порт и распространяет их на все остальные. Простой повторитель без какого-либо интеллекта. (Устарел)

- Принцип действия:
  1. Работает на физическом уровне
  2. Не хранит таблицу MAC-адресов
  3. Повторяет сигналы, увеличивая их уровень

- Проблемы безопасности:
  1. Все устройства получают весь трафик
  2. Отсутствие сегментации
  3. Атака типа MITM (Man-in-the-Middle)

## Коммутаторы (Switches)
-  **Коммутатор** — активное устройство второго уровня OSI, которое управляет передачей данных между устройствами сети на основе MAC-адресов.

- Принцип действия:
  1. Коммутатор хранит таблицу (ARP/CAM Table), связывающую порты и MAC-адреса
  2. Принимает кадр на один порт, проверяет таблицу
  3. Если адрес найден — передаёт только нужному устройству
  4. Если не найден — широковещает всем портам (кроме входящего)

- Изоляция портов:
  1. Позволяет изолировать устройства
  2. Можно настроить VLAN для логической сегментации без физического подключения
  3. Port Security

## Маршрутизаторы (Routers)
- **Маршрутизатор** — устройство третьего уровня OSI, осуществляющее маршрутизацию данных между разными сетями.

- Принцип работы с IP-адресами:
1. Маршрутизатор хранит таблицу маршрутизации (Routing Table)
2. Принимает пакеты, проверяет адрес назначения
3. Пересылает пакет по оптимальному пути к целевой сети

- Таблица маршрутизации содержит:
1. Network Address 
2. Маску подсети 
3. Gateway
4. Интерфейс
5. Метрика
6. Доп.сведения (тип маршрута, флаг по умолчанию, состояние канала, административное расстояние)
