## Классификация плагинов

- FFI плагины - по веб интерфейсу (form function interface - можно собрать на любимом языке, завернуть в си и все будет окей)
- Dbus плагины - позволяют приложениям взаимодействовать друг с другом (на шине одни регистрируют интерфейсы, другие вызывают эти интерфейсы)
- Platform channel плагины - позволяют прокидывать данные от flutter части к нативной
- Federated плагины

### FFI плагины

- Dart код
- dart:ffi 
- C ABI 
	- C/C++ библиотека
	- Rust библиотека
Дает максимальную производительность на устройствах т.к. не общаемся ч/з промежуточные слои. Может манипулировать памятью

Плюсы:
- Прямой вызов нативного кода
- Единый интерфейс С
- Прямая работа с памятью
- Высокая производительность

Минусы:
- Ограничение типов языка С
- Высокая сложность разработки
- Сборка под каждую платформу

Примеры: pdfrx_aurora

### Dbus плагины

- Dart код
- Dbus пакет
- Dbus сервис
- Системные службы

Плюсы:
- Отсутствие нативного окда
- Производительность

Минусы:
- Ограничение наличия Api
- Сложная откладка
- Ручная типизация

Примеры: geoclue_aurora

### Platform-channel плагины

Классический подход реализации плагинов

- Dart код
- MathodChannel/EventChannel/BasicMessageChannel
- BinaryNessanger
	- Java/Kotlin Binding
		- Нативный API Android
	- C++ Binding 
		- Нативный API Aurora

Плюсы:
- Единое api для платформ
- Статическая типизация
- Баланс производительности и удобства

Минусы:
- Накладные расходы на сериализацию/десериализацию
- Ручное преобразование типов и обработка ошибок

### Federated плагиныэ

Архитектурный стандарт, позволяющий создавать расширяемые плагины

- App-facing package 
- Dart API
- Platform Inteface 
- Abstract Class
	- Android Implementation
	- Aurora Implementation

Плюсы:
- Независимые части
- Раздельные реализации
- Загрузка необходимой части
- Добавление реализации без одобрения автора

Минусы:
- Усложненная разработка
- Усложненное версионирование (т.к. этот форк нужно еще поддерживать при новых версиях от автора)

Примеры: camera_aurora, vibration_aurora, url_launcher_aurora
