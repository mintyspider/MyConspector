А если мы возьмем берестяные грамоты, то там предложение начинается с буквы "А". Потом еще и точками слово от слова разделять будем с помощью точек.

## Как разделить предложение на слова?

- по пробелам: 
  - слово с запятой
  - слово с переносом/дефисом
  - слово с кавычкой/скобкой
  - слово с апострофом
  - наклонная черта
    - дроби
    - сокращения
    - просто 2 слова
- Знаки пунктуации: , . ; ! : ? / – ( ) [ ] { } “”

::: warning Но тут есть проблема
- как будто, потому что, под рукой, в соответствии с, в общем и целом
- во-первых, по-летнему, вице-адмирал, как-то
- т. е., и т. д., до н. э.
- м/с, км/ч
- itsupport\@petrsu.ru
:::

Это мы еще про иностранные языки не говорим... тот же немецкий, например.

*Lebensversicherungsgesellschaftsangestellter* (Leben — жизнь; Versicherung — страхование; Gesellschaft — компания, общество; Angestellter — служащий, сотрудник) – сотрудник компании по
страхованию жизни
:::

## Части речи (морфологический анализ)

В результате токенизации для каждого токена надо подобрать часть речи:
- имя существительное;
- имя прилагательное;
- имя числительное;
- глагол;
- наречие;
- местоимение;
- категория состояния;
- частица;
- предлог;
- союз.

Нам надо части речи и их характеристики знать для задачи генерации текста.
